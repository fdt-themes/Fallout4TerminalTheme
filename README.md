<h1 align="center">Fallout 4 Terminal Theme</h1>
<img src="https://fdt-themes.github.io/Fallout4TerminalTheme/img/FalloutTerminal.png">

<h2>About</h2>

This is Bates' second Discord theme!
Its goal is to mimic the look and feel of the VaultTec(r) terminals from Fallout 4!

<h2>Installation</h2>

<h3>Vencord / Vesktop</h3>

1. Go into Discord's settings → Themes → **Online Themes**
2. Paste this link and save:
```
https://fdt-themes.github.io/Fallout4TerminalTheme/Fallout4Terminal.theme.css
```

<h3>BetterDiscord</h3>

1. Download [Fallout4Terminal.theme.css](https://fdt-themes.github.io/Fallout4TerminalTheme/Fallout4Terminal.theme.css) (right-click → Save link as)
2. Go into Discord's settings → Themes → "Open theme folder"
3. Move the file into the folder you just opened
4. Enable the theme

<h2>Customization</h2>

The colors are at the top of the .theme.css file, written as `R, G, B` (for example `--rgb-text: 74, 239, 152;`).
If you use the Vencord online link, put your changes in Quick CSS instead:
```css
:root, .visual-refresh, .visual-refresh.theme-dark {
  --rgb-text: 74, 239, 152;
  --rgb-highlight: 74, 239, 152;
}
```
Need help picking a color? The [theme's website](https://fdt-themes.github.io/Fallout4TerminalTheme/) has a handy color picker!
